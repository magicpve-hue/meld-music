# Разработка Meld

Для запуска интерфейса установите Node.js 22+ и зависимости из README. Библиотека, очередь и выдача аудио тестируются стандартным `node:test`, поэтому для `npm test` не нужны ни сетевые загрузки, ни Spotify-ключи, ни скачанный Electron.

Пожалуйста, приложите к исправлению описание проблемы и способ проверки. Для ошибок загрузки укажите ОС, версию движка и текст ошибки. Удалите токены, ключи и приватные ссылки из журналов перед публикацией.

Не добавляйте в Git `node_modules`, скачанные аудиофайлы, папку пользовательских данных или API-ключи. Изменения списка движков делаются через `scripts/refresh-tools.cjs`, затем проверяются вручную. Обновление манифеста меняет закреплённые исполняемые файлы и должно сопровождаться проверкой их установки.

Сборка дистрибутивов: `npm run package` на macOS. Она создаёт ZIP для macOS Apple Silicon и Windows x64 в родительской папке проекта. Сборки не имеют сертификатов издателя. Наличие Windows-архива само по себе не означает, что он проверен на Windows.
