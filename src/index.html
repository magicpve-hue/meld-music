Движки загрузки

spotDL, yt-dlp, FFmpeg и Deno. Установка из зафиксированных релизов с проверкой SHA-256, примерно 200–300 МБ. Python не нужен.

Ключи Spotify необязательно

Если импорт Spotify отклоняет доступ, укажи ключи своего приложения. Они сохраняются через защищённое хранилище ОС.

Файлы и библиотека

Локальные файлы копируются в коллекцию. Удаление трека из списка сохраняет файл на диске.

Meld не снимает DRM и не обходит платный доступ. Возможность импорта и загрузки зависит от источника. Сохраняй записи, на скачивание которых у тебя есть разрешение.
