# Изменения

## 0.1.0 — 2026-10-29

- Первая версия десктопного приложения: macOS Apple Silicon и Windows x64.
- Импорт публичных ссылок Spotify через spotDL и SoundCloud через yt-dlp.
- Библиотека локальных и скачанных аудиофайлов, поиск и избранное.
- Очередь загрузок с отменой и повтором; проверка результата FFprobe.
- Воспроизведение, пауза, перемотка, громкость, перемешивание и повтор.
- Установка закреплённых движков с проверкой SHA-256.
- Автоматические тесты библиотеки и очереди; GitHub Actions для Linux, macOS и Windows.
